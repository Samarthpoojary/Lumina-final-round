# Diya Guide states

Transparent 64 × 64 SVG variants; display at 48–64 CSS pixels in the pin panel footer or a header corner, away from the circuit and controls.

- `diya-guide-idle.svg` — initial and stopped state.
- `diya-guide-selecting.svg` — while the player is choosing pins.
- `diya-guide-validation-error.svg` — when validation rejects an assignment.
- `diya-guide-sequence-active.svg` — while the LED sequence runs.

The art is visual-only. Keep validation text in the existing status area; the character asset carries no dialogue or gameplay information.
