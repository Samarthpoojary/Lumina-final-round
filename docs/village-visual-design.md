# Village visual direction

## Direction: Lantern paths

The village uses a dusk palette of deep blue-green, warm earth, leaf greens, saffron light, and muted turquoise. Rounded, quiet HUD surfaces frame a high-contrast pixel map, so the map remains the main focus while controls and inventory stay legible. Crisp 32-unit map artwork scales to the existing 24-pixel gameplay tiles; the player's canvas viewport and movement remain unchanged.

The world art gives the four existing base anchors their own silhouettes: orchard and market, pond and arch, garden and well, and a second festival market with rangoli. A broad crossroad leads to a shared courtyard and a visible lantern stall. Small lamp and flower clusters break up long paths and help the eye follow the route. The whole-village map uses the same artwork at its natural 84:64 ratio, with the current camera bounds and player marker overlaid.

This is an original arrangement and drawing set. The supplied demo was used only as a general cue for a festive top-down village; its exact map arrangement, interface layout, proportions, labels, and assets were not reproduced.

The redesign changes only map/UI presentation. Existing movement, collision, pickups, recipe, crafting, and circuit behavior stay in their existing code paths.
